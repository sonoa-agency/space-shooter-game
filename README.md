# سَديم — لعبة تصويب فضائية

لعبة تصويب فضائية بمنظور علوي، مبنية بـ React + Vite + Canvas. موجات أعداء متصاعدة، ترقيات بين الموجات، وقائمة أفضل النتائج محليًا على جهازك.

**العب الآن:** https://sonoa-agency.github.io/space-shooter-game/

## طريقة اللعب

- **الحركة:** WASD أو الأسهم — والسفينة تتبع الماوس أيضًا
- **إطلاق النار:** مسافة (Space) أو ضغطة/زر الماوس
- **إيقاف مؤقت:** Esc
- **على الموبايل:** عصا تحكم يسار الشاشة للحركة + زر إطلاق النار يمين الشاشة

## القواعد

- عندك 3 محاولات (قلوب).
- بعد كل موجة تختار ترقية: تعدد الطلقات، درع، أو سرعة.
- أفضل 8 نتائج تتحفظ محليًا في المتصفح (localStorage) — مفيش سيرفر ولا تسجيل دخول.

## التقنيات

- React 19 + TypeScript + Vite
- Tailwind CSS 4 + خطوط Tajawal و IBM Plex Mono
- رسم اللعبة على Canvas والصوت بـ Web Audio API — بدون أي ملفات صور أو صوت خارجية

## تشغيل محلي

```bash
npm install
npm run dev
```

البناء للنشر:

```bash
npm run build
```
